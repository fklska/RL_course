# Карточка проекта K04 · среды

## Исследовательский вопрос
В каких случаях предсказание BFS (число шагов и результат(успех / провал)) расходится с реальным исходом в базовой и модифицированной версии BabyAI-UnlockToUnlock-v0?

## Данные и срез
* Среда: `BabyAI-UnlockToUnlock-v0` (пакет `minigrid-3.2.0`);  
* Лицензия: Apache-2.0   
* Seed: [0, 1, ..., 499]  
* число тестовых конфигураций: N=500  
* max_steps = 1080  
* правило отбора: конфигурации среды должны быть уникальны    

## Эталон и метод
- Эталон: проигрывание той же последовательности действий в реальной среде  
- Оцениваемый оценщик: BFS по модели переходов    
- Базовое сравнение: упрощённый BFS  

## Метрика и критерий
- Метрика ошибки: Частота ошибок = (траектории, где предсказание BFS разошлось со средой хотя бы по одному полю: успех/неуспех, шаг завершения, итоговое состояние) / (все проверенные траектории)
- Численный критерий успеха:  
  - на оптимальных путях (группа 1) совпадение 100%: среда детерминирована, поэтому любое расхождение означает ошибку модели. При 0 ошибках на 500 конфигурациях верхняя 95% граница частоты ошибок ≈ 3/500 = 0,6% (правило трех)  
  - на группах 2-3 совпадение не ниже 99% - каждое расхождение разобрано и отнесено к конкретному правилу среды  
  - упрощённый BFS (базовое сравнение) ошибается заметно чаще, иначе наш тест не чувствителен (проверка, что вообще есть смысл сравнивать оценщик с базовым сравнением)


## Риск и границы
- Возможная ошибка оценщика: BFS может быть неверно реализован или использовать другую модель переходов, чем реальная среда. 
- За границами проекта: Разработка новых RL-алгоритмов, сравнение архитектур нейросетей, стохастические среды
