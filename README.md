# RL_course
## Исследовательский вопрос
Как функция награды влияет на обобщающую способность RL-агента?

## Данные и срез
MiniGrid; Unlock to Unlock; лицензия: Apache-2.0

## Эталон и метод
Эталонный исход или прокси: Минимальная длина пути, рассчитанные с помощью BFS для каждой тестовой конфигурации.
Оцениваемый оценщик: BFS как алгоритм поиска кратчайшего пути в графе состояний среды, учитывающий ключи, состояние дверей и остальные механики задачи.
Базовое сравнение: Агент, обученный с исходной функцией награды R=1-0.9T/Tmax, при фиксированном алгоритме RL и бюджете обучения. Дополнительный ориентир — случайная политика.

## Метрика и критерий
Метрика ошибки: Относительный избыток длины пути по сравнению с BFS
Численный критерий успеха: Например, успешность не ниже 90% на тестовых конфигурациях, а среднее превышение длины оптимального пути не более 20%. Эти пороги предварительные!!!

## Риск и границы
Возможная ошибка оценщика: BFS может быть неверно реализован или использовать другую модель переходов, чем реальная среда. Кроме того, разные функции награды могут давать разную скорость обучения, поэтому сравнение при неодинаковых бюджетах будет некорректным.
За границами проекта: разработка новых RL-алгоритмов, сравнение архитектур нейросетей, стохастические среды, непрерывные пространства состояний и перенос на принципиально другие задачи.
